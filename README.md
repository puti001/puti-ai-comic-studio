# Puti-AI 漫畫拼貼工具

把照片拖入漫畫分格，加上對白與特效，製作自己的漫畫。

[立即使用](https://puti001.github.io/puti-ai-comic-studio/)

[下載離線版](https://puti001.github.io/puti-ai-comic-studio/downloads/Puti-AI%E6%BC%AB%E7%95%AB%E6%8B%BC%E8%B2%BC%E5%B7%A5%E5%85%B7.html)（開啟後另存 HTML，下載完成後可直接以瀏覽器使用）

## 功能

- 34 種漫畫版型，包含經典、敘事、動感與破格。
- 照片拖放、移動與縮放，8 種邊框樣式。
- 對話框、想法框、旁白框、爆炸框與擬聲詞貼紙。
- 集中線與疾走線，可調整強度、顏色與作用分格。
- 整頁比例：1:1、4:3、3:4、16:9、9:16、A4 直式與 A4 橫式。
- 預覽、PNG／JPG 下載、列印／另存 PDF。
- 儲存及開啟 `.puti.json` 作品，支援復原與重做。

## 使用方式

1. 選擇漫畫版型和整頁比例。
2. 加入照片，拖到分格裡，再調整取景。
3. 加入文字與特效，下載漫畫。

照片在使用者瀏覽器內處理，不會由本工具上傳到伺服器。重新整理或關閉網頁前，請先按「儲存作品」，以便下次繼續編輯。

網站為純 HTML、CSS、JavaScript，所有資源使用相對路徑，不需 API 金鑰。GitHub Pages 從 `main` 分支根目錄發布。
